PRODUCCIÓN

¿Qué construimos?

Implementamos una arquitectura DevOps completa que automatiza todo el ciclo de vida de esta aplicación web: desde que el desarrollador escribe código hasta que está disponible en producción, sin intervención manual.

Cada vez que se hace un git push a GitHub, el sistema activa automáticamente las pruebas, construye la imagen Docker, la publica en Docker Hub y la despliega en Kubernetes — todo en menos de 3 minutos.

Herramientas utilizadas

GitHub
Control de versiones

Repositorio central del código. Cada push dispara el pipeline automáticamente.

GitHub Actions
Integración Continua

Ejecuta pruebas, construye y publica la imagen Docker en cada cambio.

Docker
Contenedorización

Empaqueta la app con todas sus dependencias para que funcione igual en cualquier entorno.

Docker Hub
Registro de imágenes

Almacena las versiones de la imagen lista para desplegar.

Jenkins
Entrega Continua

Toma la imagen validada y la despliega en Kubernetes de forma automática.

Kubernetes
Orquestación

Mantiene 2 réplicas de la app corriendo con auto-recuperación ante fallos.

Estado del sistema
